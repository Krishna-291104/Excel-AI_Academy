# LinkedIn Portfolio Copy

## Project Title

**ExcelAI Academy — Interactive Excel & Data Analytics Learning Platform**

## One-line Summary

A full-stack learning platform that guides users from Excel fundamentals to Data Analyst skills through structured lessons, practical datasets, quizzes, progress tracking, and achievement-based course unlocking.

## LinkedIn Project Description

Designed and developed **ExcelAI Academy**, an interactive learning platform focused on progressive Excel education and the transition into Data Analytics.

The platform combines structured beginner-to-advanced Excel lessons, practical datasets, knowledge checks, learner progress tracking, authentication, and a hidden Data Analyst pathway that unlocks after completing the Excel Intermediate milestone.

### Key features

- Beginner → Advanced Excel learning paths
- Structured lessons, modules, objectives and quizzes
- Practical dataset library
- Learner progress tracking
- Authentication and persistent progress architecture
- Conditional Data Analyst course unlocking
- Achievement experience with Samurai-inspired UI
- Data Analyst career roadmap covering Excel, SQL, statistics, visualization, BI, Python and portfolio development
- Responsive desktop/mobile interface
- PostgreSQL support with local development fallback
- Lightweight CSS-based intro with no dependency on Garp.mp4 or Zoro.mp4

### Technologies

**HTML5, CSS3, JavaScript, Node.js, REST APIs, PostgreSQL, SQL, Docker, npm**

### Portfolio Focus

This project demonstrates product thinking, learning-experience design, frontend development, backend/API architecture, authentication, database design, conditional access logic, and responsive UI implementation.
